# Build

Plugin builds resolve as a consumer of the package without project-local or host state; launch bundles resolve policy for the current project or an ad-hoc request. See [build contracts](.context/CONTEXT.md).

Route provenance (passthrough, unknown confidence) belongs in routing fields; tool permission gaps belong in rule status and notes; bundle warnings are only for actionable degraded states. Consumers launch with `routing.harness_model` verbatim: Cursor may already have encoded effort in it. Candidate slugs are diagnostic only.

See [policy](policy/AGENTS.md) for pins, preferences and fallback.
