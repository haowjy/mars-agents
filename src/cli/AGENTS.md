# CLI

The CLI chooses command policy and formats output; library modules implement the mechanisms. Project discovery walks to the filesystem root and does not stop at git boundaries.

Under `--json`, stdout must contain exactly one JSON document. Shared output helpers send status messages to stderr in JSON mode; guard raw `println!` calls explicitly.

Resolve model identity before assessing routes within the configured target scope. Availability describes the selected route and must preserve unknown evidence as unknown. See [models](../models/AGENTS.md) and [harness](../harness/AGENTS.md).
