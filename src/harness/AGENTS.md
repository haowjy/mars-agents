# Harness capabilities

Harness identity belongs to `mars-schema`. Keep installation facts separate from routing permission: an excluded harness is not an absent executable, and excluded harnesses must not be probed.

Share one lazy `CapabilitySession` and `NativeAuthCache` across a command's candidate evaluations. Authentication has an unknown state and doesn't prove credit or quota. Pi and Cursor listings imply configured authentication only while the latest credential-gated listing succeeded; OpenCode's ungated listing never does.

See [probe contracts](../models/probes/.context/CONTEXT.md).
